import Disclosure from '../../../components/Disclosure.svelte';

`Disclosure` é a abstração única do Cobogó para conteúdo expansível. Ele usa `<details>` e `<summary>` nativos, preservando semântica, teclado e comportamento do navegador sem criar uma segunda abstração só para o caso agrupado.

## Uso básico

<div class="not-content" style="margin: 2rem 0;">
  <Disclosure title="O que é o Cobogó?" client:load>
    <p>O cobogó é um elemento vazado criado em Recife para permitir ventilação e luminosidade mantendo separação espacial.</p>
  </Disclosure>
</div>

```svelte
<script>
  import { Disclosure } from 'cobogo';
</script>

<Disclosure title="O que é o Cobogó?">
  <p>Conteúdo...</p>
</Disclosure>
```

## Grupo mutuamente exclusivo

Não existe um componente `Accordion`. Para formar um grupo, dê o mesmo `name` aos disclosures. O navegador aplica diretamente a semântica nativa de `<details name="...">`: abrir um item fecha o outro item aberto do mesmo grupo.

<div class="not-content" style="margin: 2rem 0; display: grid; gap: .75rem;">
  <Disclosure title="Vão" name="gramatica-cobogo" client:load>
    <p>Use espaço, recorte e permeabilidade antes de adicionar massa visual.</p>
  </Disclosure>
  <Disclosure title="Ritmo" name="gramatica-cobogo" client:load>
    <p>Repetição cria sistema; variação controlada evita monotonia.</p>
  </Disclosure>
  <Disclosure title="Inscrição" name="gramatica-cobogo" client:load>
    <p>Texto participa da arquitetura da interface, não apenas preenche componentes.</p>
  </Disclosure>
</div>

```svelte
<Disclosure title="Vão" name="gramatica-cobogo">
  <p>...</p>
</Disclosure>

<Disclosure title="Ritmo" name="gramatica-cobogo">
  <p>...</p>
</Disclosure>
```

Essa composição é preferida a um wrapper porque a necessidade real é uma relação entre disclosures, e essa relação já possui representação nativa no HTML.

## Estado inicial e controle

`open={true}` inicia o item expandido. `bind:open` permite observar ou controlar o estado quando o domínio realmente precisa dele.

```svelte
<Disclosure title="Linha do tempo" open={true}>
  <p>...</p>
</Disclosure>
```

## Desabilitado

`disabled` impede interação por mouse e teclado e remove o `summary` da sequência de foco.

```svelte
<Disclosure title="Indisponível" disabled>
  <p>...</p>
</Disclosure>
```

## Props

| Prop | Tipo | Padrão | Descrição |
| :--- | :--- | :--- | :--- |
| `title` | `string` | **obrigatório** | Texto do `<summary>`. |
| `name` | `string` | — | Nome nativo do grupo. Reutilize o mesmo valor para exclusividade mútua. |
| `open` | `boolean` | `false` | Estado aberto; suporta `bind:open`. |
| `disabled` | `boolean` | `false` | Impede interação. |

## Acessibilidade

- usa `<details>` e `<summary>` nativos;
- não reimplementa expansão, exclusividade ou anúncio de estado com ARIA customizado;
- grupos usam o atributo HTML `name`, sem gerenciador JavaScript paralelo;
- o estado desabilitado impede mouse e teclado e é exposto com `aria-disabled`.

A regra de design aqui é simples: quando a plataforma já possui uma boa abstração semântica, Cobogó deve torná-la fácil de usar — não escondê-la atrás de outra hierarquia de componentes.

# O portfólio tem uma barra comum de qualidade

## Posição

Todo consumer ativo deve aspirar a pelo menos `3/4` em cada dimensão aplicável do Surface Quality Model. Nota total alta não compensa dimensão crítica escondida pela média.

## Racional

Qualidade pública é multidimensional. Uma UI excelente não compensa provenance enganosa; autonomia de dados não compensa navegação impraticável.

## Contrato

O ranking mostra total, mas priorização olha primeiro para dimensões 0/1, depois 2. Consumers de referência são aqueles que atingem qualidade alta sem perder identidade local.

## Critério observável

O backlog de superfície consegue apontar quais dimensões abaixo da barra têm gaps concretos e quais recomendações estão sendo usadas para elevá-las.

## Escape hatch

Dimensão genuinamente não aplicável deve ser marcada como tal em evolução futura do schema em vez de receber nota artificial; até essa extensão existir, assessments devem explicar a limitação e evitar ranking enganoso.

## Evidência

A barra é uma posição normativa inicial; será calibrada após o primeiro baseline completo.

## Falsificação

Se o baseline mostrar que 3/4 não separa adequadamente qualidade aceitável de referência, os thresholds devem ser recalibrados de forma explícita e versionada.

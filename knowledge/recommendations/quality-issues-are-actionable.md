# Avaliação só gera issue quando há ação verificável

## Posição

O Cobogó pode ser crítico e ranquear consumers, mas issues devem nascer de um gap observável com recomendação e critério de conclusão — nunca apenas de uma nota baixa.

## Racional

“UX média” é diagnóstico agregado, não unidade de trabalho. Backlog vago gera ruído e incentiva mudanças cosméticas para subir nota.

## Contrato

Issue de qualidade inclui dimensão, evidência, posição Cobogó, racional, critério verificável e pattern aplicável quando houver. Pode aceitar solução local equivalente.

## Critério observável

Ao fechar a issue, é possível recapturar a superfície e dizer objetivamente se o gap descrito desapareceu ou diminuiu.

## Escape hatch

Achados exploratórios ainda incertos ficam no assessment/knowledge até haver hipótese acionável.

## Evidência

Nenhuma ainda reconciliada sob o novo modelo.

## Falsificação

Se uma recomendação não consegue formular critério observável, ela não está madura o suficiente para virar issue de implementação.

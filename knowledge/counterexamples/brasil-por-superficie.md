# Brasil por superfície

Falha recorrente: uma interface genérica recebe cores, padrões ou nomes “brasileiros” depois que sua estrutura já está decidida.

## Sinais

- trocar a paleta removeria praticamente toda a brasilidade percebida;
- pattern de azulejo/cobogó aparece sem função de orientação, separação, ritmo ou memória documentada;
- token recebe nome brasileiro sem mudança semântica;
- mesma card grid poderia ser de qualquer framework com uma skin diferente;
- referência famosa é citada, mas nenhuma decisão implementável deriva dela.

## Regra de revisão

Perguntar para cada referência: **que regra de interface foi derivada disso?**

Se não houver resposta concreta, o material permanece pesquisa/referência e não justifica implementação.

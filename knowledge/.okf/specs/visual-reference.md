# `visual-reference`

A sourced Brazilian visual/cultural reference that records observed phenomenon, derived rule, limits, and stereotype risk.

## Current required frontmatter

- `context`
- `derived_rule`
- `phenomenon`
- `source`
- `stereotype_risk`
- `title`
- `when_not_to_use`

## Current optional frontmatter

- `description`
- `source_url`

## Boundary

A reference is design evidence, not decorative authority. Cultural scope, source and stereotype risk must remain recoverable before any derived grammar claim is treated as reusable.

# `foundation-test`

A reproducible pressure test or validation contract for a foundation.

## Current required frontmatter

- `related_issue`
- `status`
- `title`

## Current optional frontmatter

- `description`

## Boundary

A foundation test records what evidence must hold; a configured test is not equivalent to a recent successful execution.

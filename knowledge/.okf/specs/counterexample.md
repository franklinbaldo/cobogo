# `counterexample`

Negative design evidence that records a tempting but harmful interpretation so it is not repeatedly reintroduced.

## Current required frontmatter

- `review_question`
- `symptoms`
- `title`
- `violates`

## Current optional frontmatter

- `description`

## Boundary

A counterexample preserves a falsification or limit; it is not a deprecated pattern that should be copied with different styling.

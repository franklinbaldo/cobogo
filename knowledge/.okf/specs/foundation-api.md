# `foundation-api`

A public contract surface of Cobogó foundations/core whose maturity is tracked independently from consumers.

## Current required frontmatter

- `related_issue`
- `status`
- `title`

## Current optional frontmatter

- `description`

## Boundary

An API concept defines reusable contract authority. Its existence does not imply adoption by a consumer; adoption belongs in consumer evidence.

# Componentes experimentais

Esta família receberá relações/componentes especulativos da Oficina quando houver trabalho concreto.

Ela não é um catálogo antecipado de componentes. Um experimento deve nascer de uma hipótese de relação — por exemplo orientação, provenance, leitura, autoria, comparação ou transição de estado — e só depois assumir uma forma concreta.

Processo esperado:

```text
referência / relação
→ hipótese formal
→ specimen
→ captura e pressure test
→ evidência positiva ou negativa
→ eventual promoção para pattern/core quando o gate apropriado existir
```

Nomes culturalmente situados podem inspirar specimens, mas o nome não substitui uma tarefa de interface nem cria semântica compartilhada por si só.

# Estudo: campos interligados na web

Este estudo procura uma alternativa à coleção de caixas independentes. A qualidade em observação é a relação entre áreas: contraste suficiente para cada campo existir, continuidade suficiente para o conjunto ser lido como uma composição. O contorno específico da referência não é o objeto da tradução.

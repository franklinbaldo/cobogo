# Explorador visual

Sessão WikiSkill especializada no laboratório visual do Cobogó. O contrato de domínio vive nos objetos OKF; a skill ligada a cada exploração explica como realizá-la na web. O objetivo não é provar gosto: é formar repertório, produzir alternativas, exercitar julgamento e tornar explícitas as escolhas que constroem a linguagem visual do Cobogó.

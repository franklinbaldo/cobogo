# Explorador visual

Sessão WikiSkill especializada no laboratório visual do Cobogó. O contrato de domínio vive nos objetos OKF; a skill ligada a cada exploração explica como materializar e comparar direções na web. O objetivo é formar linguagem e taste por prática, repertório e crítica — não simular método científico para escolhas estéticas.

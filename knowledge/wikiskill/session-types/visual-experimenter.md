# Explorador visual

Sessão WikiSkill especializada no laboratório visual do Cobogó. O contrato de domínio vive nos objetos OKF; a skill ligada a cada exploração explica como realizá-la na web. O objetivo não é provar uma proposição estética, mas desenvolver repertório, comparar direções e tornar explícito o julgamento de design.

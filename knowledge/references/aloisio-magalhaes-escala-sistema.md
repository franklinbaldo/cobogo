# Aloisio Magalhães - identidade que atravessa escalas

O interesse para o Cobogó está no caráter programático: uma linguagem visual precisa continuar reconhecível quando muda de suporte e de tamanho. A exploração deve trabalhar essa relação na web, procurando parentesco entre módulos pequenos, médios e dominantes sem reduzir o sistema à repetição mecânica de uma única caixa.

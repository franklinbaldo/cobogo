# Explorador visual

Especialização local do Experience canônico do Wisk para o laboratório visual do Cobogó.

O contrato de domínio continua sendo o laboratório atual: referência → direções de tradução → baseline → exploração → crítica posterior → eventual canonização. O Wisk fornece ciclo, persistência e aprendizagem; esta SessionType fornece o julgamento e a política visual específicos do Cobogó.

---
title: Grid e Column viram um pattern CSS
date: 2026-09-04
type: changed
---

Remove os componentes Svelte `Grid` e `Column`. O mesmo contrato de layout passa a ser oferecido por `cobogo/patterns` via `data-cobogo-pattern="grid"` e custom properties responsivas, permitindo uso direto em Astro/HTML sem wrappers de framework.
